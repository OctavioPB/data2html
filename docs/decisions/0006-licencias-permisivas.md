# ADR 0006 — Solo dependencias con licencia permisiva

**Estado:** aceptada · 2026-10-11

## Decisión
MIT, Apache-2.0, BSD o equivalentes. Elegidas: ECharts (Apache), Glide Data Grid (MIT),
CodeMirror 6 (MIT), react-grid-layout (MIT). Descartadas: HyperFormula (GPLv3/comercial),
AG Grid Enterprise (comercial).

## Consecuencias
Mantiene abierta la opción de distribuir o vender la app. No hay fórmulas de celda estilo
Excel: las columnas calculadas son expresiones SQL.
